# Security policy

This project intentionally contains insecure Terraform configurations for
testing. A scenario behaving insecurely as documented is not a vulnerability.

Please report vulnerabilities in the repository's private **Report a
vulnerability** flow on the Security tab. Do not disclose vulnerabilities in
public issues, discussions, or pull requests.

Include affected versions or commits, reproduction steps, impact, and any
proposed remediation. Maintainers will acknowledge a report as soon as they
can and coordinate disclosure after a fix is available.
